# POS Toolkit für easyBasar

Inoffizielle Chrome Erweiterung des Ski Club Rötteln e.V. für die interne Organisation des Skibasars auf easybasar.de. Die Erweiterung wird nicht öffentlich gelistet und nur an die Helfer des Vereins verteilt.

Dieses Repository enthält die [Datenschutzerklärung](datenschutz.md) der Erweiterung.
